# Tugas Rutin 9 — Setup Laravel

Tugas ini adalah bagian dari mata kuliah Pemrograman Web. Proyek ini berisi konfigurasi awal instalasi Laravel, *routing* dinamis, pembuatan *controller* dan *model*, serta kustomisasi *view* menggunakan Blade template dan Tailwind CSS CDN.

## 🛠️ Persyaratan Sistem (Prerequisites)
Pastikan komputer Anda sudah terinstal:
- **PHP** (Disarankan versi 8.1 ke atas)
- **Composer** (Dependency Manager untuk PHP)
- **XAMPP / Laragon** (Apache & MySQL Database)
- **Git**
